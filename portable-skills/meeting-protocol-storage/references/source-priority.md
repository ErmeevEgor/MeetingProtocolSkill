# Source priority

Use evidence in this order:

1. current user corrections/instructions;
2. current meeting transcript;
3. supplied project/context files;
4. previous protocol only after confirming same project/stage;
5. deterministic calendar conversion from explicit meeting date + unambiguous relative date.

Rules:

- Newer current-meeting facts override older protocol facts.
- A previous protocol from another project is format-only evidence.
- File names can help identify a source but do not prove a participant role or business decision.
- Transcript metadata can establish meeting date, duration, source and participant count, but participant count alone does not establish names.
- Do not use public web search to fill missing project facts unless explicitly requested.
